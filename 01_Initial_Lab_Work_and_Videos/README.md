# Initial Lab Work and Video Demonstrations

This folder contains module-wise lab work and video demonstrations completed during the Selenium Python Automation program.

## Modules

### M1 - Selenium Automation

Covers Selenium WebDriver and web automation concepts, including web elements, locators, browser navigation, waits, alerts, frames, multiple windows, screenshots, and advanced browser interactions.

### M2 - Unit Testing and Page Object Model

Covers unit testing with PyTest, test organization, assertions, fixtures, Page Object Model, reusable components, and basic automation framework concepts.

### M3 - BDD and REST API Automation

Covers Python BDD using Behave and Gherkin, REST API testing, HTTP methods, request and response handling, API validation, reusable step definitions, response handling, and advanced API testing concepts.

### M4 - Robot Framework

Covers Robot Framework with SeleniumLibrary, reusable keywords, resource files, setup and teardown, tags, data-driven testing, assertions, screenshots, alerts, dropdowns, waits, browser navigation, and e-commerce automation.

## Video Demonstrations

This folder also contains video demonstrations of selected practical exercises and assignments completed during the training. These videos provide a visual demonstration of the automation scripts, test execution, and expected results.

## Purpose

The purpose of this section is to document and showcase the practical work completed throughout the training program and demonstrate the application of Selenium Python automation concepts through hands-on assignments.
