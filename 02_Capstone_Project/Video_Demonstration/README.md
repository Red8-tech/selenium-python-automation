# Selenium Python Automation Framework

A scalable Selenium Web Automation Framework built with **Python, Selenium WebDriver, PyTest, Unittest, and Page Object Model (POM)**.

### Key Features
- Page Object Model (POM)
- Chrome & Firefox automation
- Configuration management
- CSV-based test data
- Explicit waits
- Logging
- Automatic screenshots on failure
- PyTest HTML reporting
- Allure reporting
